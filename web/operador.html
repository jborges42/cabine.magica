Conectar o número

Ler o QR Code com o seu celular

  1. O número emissor precisa estar no app WhatsApp Business (versão 2.24.17 ou mais nova), em uso há pelo menos 7 dias. O WhatsApp comum não serve, mas dá para migrar o número para o Business no próprio celular.
  2. Acesse o painel do parceiro oficial da Meta 360dialog (hub.360dialog.com) → Add channel → entre com o Facebook do SENAI.
  3. Digite o número e escaneie o QR Code com o app WhatsApp Business. O número continua funcionando no seu celular, e você vê lá cada foto enviada.
  4. Gere a API key no painel e cole abaixo.
  5. Abra o app no celular pelo menos a cada 13 dias, senão a conexão cai.

Número dedicado na Cloud API

  1. Em developers.facebook.com, crie um app do tipo WhatsApp no portfólio do SENAI.
  2. Registre um número que não esteja em uso no WhatsApp (chip novo ou fixo). Ele é verificado por SMS ou ligação.
  3. Em Configurações do negócio → Usuários do sistema, gere um token permanente com whatsapp_business_messaging e whatsapp_business_management.
  4. Cadastre uma forma de pagamento e copie o Phone number ID (WhatsApp → API Setup).

Enviar um teste

Manda agora a foto mais recente da cabine (ou uma imagem de teste) usando o template configurado. Use para validar o número, o token e o template antes do evento.

Template a aprovar

Pessoas que nunca falaram com o SENAI só podem receber template aprovado. Crie no WhatsApp Manager (aprovação em até 24 h, então faça dias antes do evento):

Nome: foto_cabine_magica
Categoria: Utilidade (Utility)
Idioma: Português (BR)
Cabeçalho: Imagem (use uma foto da cabine como exemplo)
Corpo: Olá! Aqui está a foto que você tirou na Cabine Mágica do SENAI Fraiburgo, no Mundo SENAI 2026. Obrigado pela visita!
Rodapé: SENAI Fraiburgo

Não escreva nada promocional (cursos, matrículas, links), porque a Meta muda a categoria para Marketing, que custa cerca de 9 vezes mais. Verifique o CNPJ do portfólio antes do evento: sem verificação, o limite é de 250 pessoas por dia.
